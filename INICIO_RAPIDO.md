# 🚀 Inicio Rápido

## Instalación en 3 Pasos

### 1. Instalar dependencias
```bash
pip install -r requirements.txt
```

### 2. Ejecutar el sistema
```bash
python main.py
```

### 3. ¡Listo! 🎉

## Ejemplo de Uso Básico

### Paso 1: Registrar Insumos
1. Ve a la pestaña "📦 Insumos"
2. Agrega tus insumos:
   - Harina: 5 kg, $2.50/kg
   - Aceite: 2 L, $3.00/L
   - Carne: 1 kg, $8.00/kg

### Paso 2: Crear Lote de Masa
1. Ve a "🥟 Masas"
2. Crea un lote "Masa tradicional"
3. Selecciona los insumos usados y cantidades

### Paso 3: Definir Rendimiento
1. Ve a "📊 Rendimiento"
2. Selecciona el lote creado
3. Indica: "De este lote salen 20 empanadas"

### Paso 4: Registrar Producto
1. Ve a "🍽️ Productos"
2. Crea "Empanada de carne"
3. Asocia la masa y agrega relleno (carne)
4. Precio: $1.50, Demanda: 15/día

### Paso 5: Ver Costos
1. Ve a "💰 Costos"
2. Verás el costo unitario calculado automáticamente
3. Verás ganancia y margen

### Paso 6: Optimizar
1. Ve a "⚡ Optimización"
2. Define demanda mínima por día
3. Define fondos disponibles
4. Resuelve y ve la producción óptima

## 💡 Consejos

- Los datos se guardan automáticamente
- No necesitas medidas exactas, usa proporciones
- Puedes tener múltiples tipos de masa
- El sistema calcula todo automáticamente
